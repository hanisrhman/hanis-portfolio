# Hanis Portfolio

A personal portfolio website built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Sections

- Hero
- About
- Projects
- Experience
- Timeline
- Achievements
- Tech Stack
- Contact

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Framer Motion
- React Icons

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

Lint source code:

```bash
npm run lint
```

## Profile Configuration

Update your personal information in `src/data/profile.ts`:

- name and role
- email and phone
- location
- GitHub and LinkedIn URLs
- resume URL

## Assets

Public images and resume are stored in `public/`.
